# Wave 2 Brief — What Wave 1 Taught Us (concept-generation constraints)

Distilled from w1-market-landscape.md, w1-breakout-autopsies.md,
w1-novel-mechanics.md, w1-retention-monetization.md, w1-virality-distribution.md.

## The formula every 2023-26 breakout shares

1. **Familiar verb + exactly ONE fresh twist.** Players already know the base
   activity; the twist is the product. (Balatro=poker+roguelite scoring;
   Arrows=tap-order rule; Dragonsweeper=Minesweeper+RPG info layer.)
2. **Fun lands in ≤60-90 seconds.** Tutorial ≤2 guided steps. The real meta can
   hide for hours; the toy must be joyful in minute one.
3. **Clip-ability is a spec, not luck.** A 10-15s vertical, center-framed
   spectacle moment (cascade / jackpot / last-second save / transformation).
4. **One-glance visual identity** — a cropped screenshot must be unmistakable.
5. **Retention moat vs clones**: depth that takes months to copy (systemic
   depth, content pipeline, community) — clones arrive within 8-12 weeks of
   any organic hit (Arrows was cloned into the top 10 in months).

## Hard constraints (buildability + market)

- Builder: solo owner + Claude. Proven stack: PixiJS v8 + TS + Vite (web),
  Expo native shell, WebAudio synth, runtime atlases, screenshot/perf harness.
  60fps on mid phones; p95 frame < 17.5ms discipline already in place.
- Distribution: web-first (itch.io + Poki/CrazyGames + own domain) → Discord →
  micro-creator seeding → mobile stores with pre-reg. Game must be playable
  instantly in browser.
- Monetization: rewarded-video-first + $2.99-4.99 starter/remove-ads pack +
  supporter pack; optional seasonal pass later. NO gacha/loot boxes/fake
  timers (EU Digital Fairness Act late 2026). Web D2C keeps ~95%.
- Retention bar to beat: 35/15/5 D1/D7/D30 (breakout = 40/20/10).
- Session shape: 2-6 min rounds, one-thumb portrait, interrupt-safe.
- AVOID genres: match-3, 4X survival, MMORPG/idle RPG, slots, generic block
  puzzle (clone-bait without moat), another idle battler (that's our v1).

## Open design spaces to draw from (validated gaps)

A. Sensor-native puzzle toy (Blackbox successor; LiDAR/UWB/ML-vision unused).
B. Widget/Live-Activity-first game (lock screen + Dynamic Island primary).
C. Real-world-data-as-rules (weather, daylight, steps, calendar as parameters).
D. REAL-physics satisfying toy + light goal economy (TikTok ASMR audience
   served only by fake-physics shovelware; real sim + haptics unbuilt).
E. Balatro-wrap on un-mined host toys: mahjong, dominoes, darts, dice-poker,
   coin pushers, pachinko-adjacent.
F. Mobile anomaly-spotting (Exit 8-like; portrait 30s rounds don't exist).
G. Haptics/audio-as-information; the "earbud game" slot is vacant.
H. Daily-puzzle-shaped judgment/persuasion games (2-min daily, share square).
I. Deduction-grid retheme (Dragonsweeper path: reskin a solved classic's
   information system).
J. Crowd-as-brush: thumb-steered thousand-agent swarms (touch is the perfect
   input; no flagship owns it).
K. One-rule puzzle subgenre invention (the Arrows path — but with a moat).
L. Underserved audiences: seniors, 30+ women, commuters/earbud, "second
   screen while watching TV".

## Concept output format (every concept MUST use this)

- **Name** (working title)
- **One-line pitch** ("wait, what is that game?" test)
- **Core verb + the one twist**
- **First 60 seconds** (what the player literally does)
- **The clip moment** (describe the 10-15s vertical video)
- **Share artifact** (the Wordle-square equivalent)
- **Daily/retention shape** (why D7 and D30 exist)
- **Depth/moat** (why a clone in 8 weeks would be shallow)
- **Monetization fit** (rewarded + starter pack mapping)
- **Buildability** (how it maps to PixiJS/TS/web; hardest technical risk)
- **Originality check** (searched — what's the closest existing game and why
  this is different)
