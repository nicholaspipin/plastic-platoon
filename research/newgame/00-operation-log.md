# All-Night Research Operation — New Original Mobile Game

Goal: by ~07:00 on 2026-08-10, produce GAMEPLAN.md — a full, detailed, buildable
plan for a completely fresh, original mobile game with breakout potential.
Builder context: solo owner + Claude, proven stack (PixiJS v8 + Vite + TS web,
Expo native shell), shipped Plastic Platoon (idle battler). New game must NOT
be another idle battler reskin — original mechanic, original feel.

## Planned waves

- **Wave 1 — Broad sweep** (market landscape, breakout-hit autopsies, novel
  mechanics space, retention/monetization science, virality & distribution)
- **Wave 2 — Gap analysis + concept generation** (cross findings → underserved
  spaces → generate 8-12 original concepts)
- **Wave 3 — Concept stress-testing** (judge panel: originality, buildability,
  virality, retention; kill weak ones, deep-research the survivors)
- **Wave 4 — Deep dive on winner** (mechanic math, feel/juice reference,
  art direction, audio, tech risks, comparable-game numbers)
- **Wave 5 — Plan drafting + adversarial review** (write GAMEPLAN.md, then
  attack it: scope realism, fun-theory holes, monetization ethics, D1 hook)
- **Morning — Final synthesis** (polish GAMEPLAN.md, executive summary)
